# Balance a radiator valve: close it counting turns, then reopen it by half

A heating mechanic balances a system by closing a valve, counting the turns, and reopening it by a set share. The stem does not rise and the wheel looks the same on every turn, so nothing in view records the count. Here the start opening differs by seed, so the target is unknown until the wheel has been closed and counted.

**One arm does this task.** The second arm is not needed, and neither the scene nor the score asks for it.

## Requirements

- `yam-isaac-lab-arena` with Isaac Lab-Arena 0.3.1 (`source <ARENA_DIR>/yam.env`).
- `mechkit.py` and `demokit.py`, in this folder. Importing `mechkit` hooks `yam_arena.scene` and `yam_arena.inspect_embodiment` without modifying them.

## Run a trial

From this folder. `--seed` sets the start opening, through the seed that `inspect-robots run` derives from it and passes to the reset: that seed modulo 3 of 0, 1, 2 starts 2, 3, 4 turns open. `--seed 1` gives reset seed 2566101560, and so 4 turns. `demokit.py --seed` passes its seed as it is. The score record gives both.

```bash
inspect-robots run --embodiment yam_arena -E task=task.py -E object_jitter=0 -E control_hz=20 \
    -E cam_width=320 -E cam_height=176 --policy dream -P rows_per_request=20 --scorer task_score --max-steps 1200 --seed 1 \
    --instruction "Close the valve fully, counting the turns as you go, then open it again by exactly half that number of turns, and let go."
```

## The demo

```bash
python demokit.py task.py OUT --seed 1
```

It is closed loop on the wheel's angle modulo one turn, as a camera could read the mark: it never reads how far open the valve is. It unwraps that angle itself, knows closed when the wheel stops, and stops at half. At the 3-turn start it takes 572 steps, 28.6 s of simulated time, about 70 s of wall time alone on one GPU at 640 x 360.

`python check_scorer.py` checks every score line on hand-built states, with no simulator. A fixed opening of 1.5 turns after closing scores 1.0 at the 3-turn start and 0.25 at the others.

## Scoring

`--scorer task_score` prints the total. Per-step `info` is not saved, so the task writes its record to `valve_scores/` (or `$VALVE_SCORE_DIR`) every second.

- **1.0:** closed to its stop first (within 0.02 turn, in the scorer), and now open by half the start count within 0.2 turn, every fingertip point at least 3 cm from the wheel and knob, the wheel still, held 1 s.
- **0.25:** closed to its stop first and now open by more than 0.05 turn, but any other part of that fails.
- **0:** never closed to its stop, or left within 0.05 turn of closed.

## Assets

Every mesh is generated by `task.py` and `mechkit.py`. There are no textures and no third-party assets.
